# Cytryna – holenderskie czasowniki dla dzieci

Aplikacja do nauki odmiany holenderskich czasowników przez osoby, po polsku.

- **4 czasy** z prostym wyjaśnieniem i przykładami: teraźniejszy (OTT), przeszły prosty (OVT), przeszły dokonany (VTT) i przyszły (*gaan* + bezokolicznik).
- **Ćwiczenia**: 70 najczęstszych czasowników, każdy w 2 losowych osobach, w losowej kolejności (20 / 40 / 70 / 140 pytań). Pytanie ma 4 odpowiedzi do wyboru, a po błędzie można spróbować ponownie.
- **Podsumowanie**: procent poprawnych odpowiedzi za pierwszym razem oraz lista błędów z wyjaśnieniem. Błędy można od razu powtórzyć.
- **Sprawdź czasownik**: wpisz dowolny czasownik, także nieregularny, rozdzielny albo formę typu *liep*, wybierz osobę i zobacz poprawną formę we wszystkich czasach.

Uruchomienie: otwórz `index.html` w przeglądarce. Nie trzeba niczego instalować.
Testy silnika odmiany: `node tests/conjugate.test.js`.
